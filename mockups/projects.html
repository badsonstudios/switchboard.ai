Model. Project = one repo (keyed by git's common directory, so all of its worktrees land in one card; today's automatic folder groups key by the checkout's own top folder, which would split them). Worktree = a branch in a folder, primary or not. Session = what it is today, with an optional worktree. Several sessions per worktree are allowed.
