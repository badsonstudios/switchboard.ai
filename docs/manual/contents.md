# switchboard.ai — User manual

Everything the app does, one page per subject. **New here? Start with
[Day one](00-day-one.md)** — it is the shortest path through a day of work, and
it links to every other page as you need it.

Every page has a **☰ Contents** link at the top right and another at the
bottom that brings you back here. The `‹` button in the header steps back one
page at a time.
